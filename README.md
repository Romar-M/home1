## Функциональность

### Основные возможности:
- **Маскировка номеров банковских карт** - преобразует номер в безопасный формат
- **Маскировка банковских счетов** - скрывает большую часть номера счета
- **Форматирование дат** - конвертирует даты в удобный формат
- **Фильтрация операций** - отбор операций по статусу
- **Сортировка операций** - упорядочивание по дате
- **Генераторы данных** - работа с транзакциями через итераторы
- **Логирование операций** - отслеживание выполнения функций
- **Загрузка данных** - чтение транзакций из JSON-файлов
- **Конвертация валют** - автоматическое преобразование сумм в рубли
- **Поддержка различных форматов данных** - чтение транзакций из CSV и Excel файлов
- **Поиск по описанию** - фильтрация операций по ключевому слову с использованием регулярных выражений
- **Анализ по категориям** - подсчёт количества операций по типам (Перевод, Вклад и др.)
- **Интерактивный интерфейс** - консольная программа для пошаговой фильтрации и просмотра транзакций

### Генераторы:
- **`filter_by_currency()`** - фильтрация транзакций по заданной валюте
- **`transaction_descriptions()`** - получение описаний транзакций
- **`card_number_generator()`** - генерация номеров карт в заданном диапазоне

### Декораторы:
- **`@log`** - декоратор для логирования успешных выполнений и ошибок функций

### Загрузка данных:
- **`load_operations()`** - загрузка данных из JSON-файлов
- **`load_transactions_from_csv()`** - загрузка данных из CSV-файлов
- **`load_transactions_from_excel()`** - загрузка данных из Excel-файлов
