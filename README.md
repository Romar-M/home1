# Система обработки банковских карт и счетов клиентов базы.

Система для обработки банковских операций, предоставляющая функции маскировки конфиденциальных данных, работы с датами и фильтрации операций.

##  Функциональность

### Основные возможности:
- **Маскировка номеров банковских карт** - преобразует номер в безопасный формат
- **Маскировка банковских счетов** - скрывает большую часть номера счета
- **Форматирование дат** - конвертирует даты в удобный формат
- **Фильтрация операций** - отбор операций по статусу
- **Сортировка операций** - упорядочивание по дате

### Модули:
- `masks.py` - функции маскировки карт и счетов
- `main.py` - основные функции обработки данных
